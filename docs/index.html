Biological laboratory work, with one place for everything

This taxonomy was built the MECE way, mutually exclusive and collectively exhaustive, to map out the outputs of wet-lab bench work. Every workflow is filed by the output it exists to produce, so each one sits in exactly one place, never two. Research area and material are filters, not branches, because one workflow can span many of both.

Nothing matches those filters. Try a broader search.

The structure, the splitting rule and a critical review are in TAXONOMY.md. This map is a synthesis, not a published standard, and has not been validated against a protocol corpus.

Wet-lab work only. Computational biology is deliberately excluded.
